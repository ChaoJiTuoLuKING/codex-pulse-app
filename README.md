## 支持哪些电脑？

| 项目 | 当前支持情况 |
| --- | --- |
| Mac 芯片 | Apple M 系列 |
| 系统版本 | macOS 13 及以上 |
| Mac 笔记本、台式机 | 符合上述条件即可 |
| Intel Mac | 暂不支持 |
| Windows | [Windows 11 x64 内测版](https://github.com/ChaoJiTuoLuKING/codex-pulse-windows-app) |

不确定电脑型号？点击屏幕左上角苹果标志 →「关于本机」。

## 三步安装

1. 下载上方 ZIP 并解压，双击里面的 DMG 安装包。
2. 把 **Codex Pulse** 拖进 **Applications（应用程序）**。
3. 从「应用程序」打开 Codex Pulse，点击屏幕顶部菜单栏的红绿灯图标。

**打开后没有大窗口是正常的，请看顶部菜单栏。**

首次打开被系统拦住、开启通知或从旧版升级，请查看 [安装手册](安装手册.md)。

## 可以做什么？

- **查额度**：在菜单栏查看额度状态，点开面板看详情。
- **收提醒**：检查到有效的明确重置预告时，通过桌面通知提醒。
- **看日历**：回看历史重置消息和对应日期。

重置消息约每 10 分钟检查一次，数据来源也按约 10 分钟周期采集，并非即时提醒。蓝点表示有有效预告，不代表额度已经到账；电脑休眠、断网或软件退出时，无法保证及时通知。实际额度请以 Codex 中的显示为准。
